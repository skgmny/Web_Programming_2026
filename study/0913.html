[목록 나열 List]

웹페이지에서 순서가 있는 리스트, 순서가 없는 리트스, 그리고 용어를 설명하는 리스트 등 다양한 형식의 목록을 만드는 3가지 태그를 다룬다.

ul은 순서가 없는 목록 unordered list

각 항목 앞에 작은 불릿(기호)가 붙는다

  • 목록의 각 항목은 반드시 li 즉 list item 태그로 감싼다

ol은 순서가 있는 목록 ordered list

각 항목 앞에 숫자나 기호가 자동으로 부여된다.

  1. 목록의 각 항목은 반드시 li 즉 list item 태그로 감싼다
  2. 목록의 각 항목은 반드시 li 즉 list item 태그로 감싼다
  3. 목록의 각 항목은 반드시 li 즉 list item 태그로 감싼다

dl은 용어를 설명하는 목록 description list/ definition list

사전처럼 용어와 그에 대한 설명을 짝지어 나열할 때 사용

dl은 설명 목록 전체 틀을 감싼다

dt는 description term으로 설명할 용어/단어를 적는다
dd는 description data로 해당 용어에 대한 헤설/설명을 적는다. 화면에서 자동으로 들여쓰기가 된다.
